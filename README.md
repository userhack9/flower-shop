# Лепесток - лендинг цветочного магазина

> **Демонстрационный проект, созданный в учебных целях.**
> Это не настоящий магазин: никакого реального бизнеса за сайтом нет.

**Живое демо:** https://flower-shop-nine-rosy.vercel.app

Адаптивный одностраничный сайт цветочного магазина с быстрой доставкой букетов. Сделан в рамках обучения работе с Claude Code и создания сайтов по шаблонам.

## Важно: данные тестовые

В проекте **нет никаких реальных данных**. Всё, что показано на сайте, придумано для демонстрации:

- название магазина «Лепесток» вымышленное;
- телефон `+7 (999) 000-11-22` и адрес «г. Москва, ул. Цветочная, 12» - заглушки;
- названия и цены букетов - тестовые, купить их нельзя;
- форма заявки - имитация: данные нигде не сохраняются и никуда не отправляются, серверной части нет;
- картинки - собственные SVG-иллюстрации, не фотографии реальных товаров.

Не вводите в форму настоящие персональные данные. Они всё равно никуда не передаются, но делать этого незачем.

## Возможности

- каталог букетов и быстрый выбор по поводу;
- форма заказа с проверкой полей на стороне браузера (имя, телефон, дата);
- таймер обратного отсчёта до конца текущего дня;
- свечение кнопок при наведении и волна при нажатии;
- адаптивная вёрстка для телефона и компьютера, видимый фокус для клавиатуры, поддержка `prefers-reduced-motion`;
- шрифт Inter хранится в проекте, внешние ресурсы не загружаются.

## Технологии

Чистые HTML, CSS и JavaScript без фреймворков, зависимостей и сборки.

## Запуск локально

Откройте `index.html` в браузере или запустите простой сервер:

```bash
python3 -m http.server 8080
```

После этого откройте http://localhost:8080.

## Структура проекта

```
index.html        разметка страницы
css/style.css     стили и переменные оформления
js/main.js        меню, таймер, форма, волна на кнопках
js/validate.js    проверка полей формы
img/              SVG-иллюстрации и логотип
fonts/            шрифт Inter (woff2)
```

## Развёртывание

Сайт размещён на Vercel и обновляется автоматически при каждом изменении ветки `main`.
